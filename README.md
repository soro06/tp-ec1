# Travaux pratiques

## Organisation
Chaque TP est contenu dans un dossier. Ainsi TP1 dans le dossier tp1, TP2 dans dossiers tp2 et TP3 dans le dossier tp3.


## Réponses qux question

Les réponses aux questions se trouvent dans le fichier Compte rendu(au format word) de chaque tp et les fichiers demandés dans le sous dossier fichiers de chaque tp
